# Excel-SQL 互转工具

## 项目概述
基于浏览器的桌面风格 Web 应用，无需后端，无需登录。

## 功能
1. **Excel → SQL**: 解析 Excel 文件，根据标题行生成 INSERT/UPDATE/DELETE 语句
2. **SQL → Excel**: 解析 SQL 语句，生成可下载的 Excel 文件

## 技术栈
- 纯 HTML + CSS + JavaScript
- SheetJS (xlsx) 库用于 Excel 解析和生成
- 纯前端，无需服务器

## 使用方式
直接用浏览器打开 `index.html` 即可

## 界面风格
- 桌面应用风格，深色主题
- 两个功能标签页切换
- 文件拖拽上传# sql_utils
